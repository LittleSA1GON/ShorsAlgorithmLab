How a quantum computer would break RSA

RSA encryption is safe because splitting a big number into its two prime factors takes classical computers far too long. Shor's algorithm would let a large quantum computer do it quickly. Watch the six steps below, then try it yourself in the lab.

mod N
the remainder after dividing by N, like hours on an N-hour clock
period r
how many steps a repeating pattern takes before it starts over
qubit
a quantum bit; many qubits can hold many values at once
measure
reading the qubits, which returns one value at random

Learn it in six steps

Press Play on each animation. Use Next to move through it at your own pace.

1

The lock: multiplying is easy, undoing it is hard

  1. Two secret primes. The amber spheres are two prime numbers, p and q. Only the owner of the key knows them.
  2. Multiply them. Their product N is published as the public key. Anyone can use N to lock (encrypt) a message, but unlocking it needs p and q.
  3. Try to undo it. An attacker has to guess factors of N. For a real 617-digit N, the best classical methods would take far longer than a lifetime.
2

The trick: factoring hides a repeating pattern

  1. A 15-hour clock. Take N = 15. Counting "mod 15" means wrapping around after 14, like a clock with 15 hours. Pick a = 2 and start at 1.
  2. Keep multiplying by 2. 1 → 2 → 4 → 8. The next step gives 16, which wraps around to 1.
  3. The pattern repeats every 4 steps, so r = 4. From r we get the factors: 2² − 1 = 3 and 2² + 1 = 5, and 3 × 5 = 15. For big N, finding r this way takes too long. That is the step a quantum computer speeds up.
3

Quantum step 1: try every power at once

  1. Start with one value. Each bar is one possible exponent x, from 0 to 15. Bar height shows its amplitude. Everything starts on x = 0.
  2. Hadamard gates spread it out. Now all 16 values of x are present at once, with equal amplitude.
  3. Compute 2x mod 15 for all of them together. Each bar gets a color for its answer: 1, 2, 4, 8, then the same four again. The colors repeat every 4 bars, so the period is now hidden inside the qubits.
4

Quantum step 2: interference finds the rhythm

  1. A comb. Values that share the same color sit every 4 positions, like the teeth of a comb (now with 64 positions).
  2. The inverse quantum Fourier transform. It makes waves that cancel out almost everywhere and add up only at a few spots, like ripples in a pond.
  3. Four tall peaks remain, at 0, 16, 32 and 48: evenly spaced by 64 ÷ 4. The spacing reveals r = 4.
5

Measure, then a little arithmetic

  1. Measure. Reading the qubits picks one peak at random.
  2. We got y = 16. Only that value is left. The rest of the state is gone.
  3. Turn it into r. 16 / 64 simplifies to 1 / 4, and the bottom number is the period: r = 4.
  4. Get the factors. gcd(2² − 1, 15) = 3 and gcd(2² + 1, 15) = 5. If we had read y = 0 or y = 32, we would simply run again.
6

The fix: encryption without a pattern

  1. A lattice. A grid of points built from a few arrow directions. Real systems use hundreds of dimensions instead of 3.
  2. Add a little noise. The public key is a point (amber) slightly off a secret grid point.
  3. Find the secret point (cyan). There is no repeating pattern for the Fourier transform to find, and no known quantum algorithm does it quickly. NIST standardized these schemes in 2024: ML-KEM (FIPS 203) and ML-DSA (FIPS 204), with hash-based SLH-DSA (FIPS 205) as an alternative.
